## 2. Project Overview
* **Application Name**: StreamClips Hub (also known as `YT-Timestamp-saver` or `StreamSnip`).
* **Purpose**: A live-clipping dashboard and management platform for content creators and streamers. It allows moderators and viewers to save timestamps and description tags in real-time during live streams (e.g., using chat integration commands like Nightbot `!clip`), automatically fetches metadata, and serves them on a sleek, interactive dashboard.
* **Repository Layout**:
  * `/FrontEnd`: Source for static/vanilla web elements, including `index.html` (core dashboard), `option.js` (dashboard scripts/Supabase client logic), `option.css` (custom design variables), and a 3D-scrolling preview page (`3d-demo.html`/`3d-demo.js`).
  * `/components/ui`: Shadcn-style React components (`header-1.tsx`, `footer-section.tsx`, `suggestive-search.tsx`, etc.) to migrate features towards a modernized React layout.
  * `/BackEnd`: Node.js Express server (`index.js`), YouTube Data API integrations (`youtube.js`), scraper utilities (`scraper.js`), database connector (`supabase.js`), and SQL migration scripts.
  * `/dist`: Output directory generated by the custom build runner (`build.js`).

## 3. Tech Stack & Architecture
* **Frontend**:
  * Core layout: HTML5, CSS3, Tailwind CSS (Tailwind CDN integration with custom class extensions).
  * Video Player: `Plyr.io` & YouTube IFrame Player API.
  * 3D Video Scrubbing: Scroll-tied responsive HTML5 `<canvas>` rendering engine with automatic pre-decoding, image bitmap caching, and zero-flicker immediate-frame rendering.
  * React/Next.js transition: Equipped with shadcn, Radix UI, Framer Motion, and Lucide React components under `/components/`.
* **Backend**:
  * Runtime & Framework: Node.js, Express, CORS.
  * Integration Services: YouTube Data API v3 (live state checks, stream metadata, and channel stats), game details scraper.
  * Automated Operations: Nightbot Command Endpoints (`/api/clip`), automatic cleanup of unstarred/non-favorite clips older than 30 days.
* **Database**: Supabase PostgreSQL client integration.

## 4. Current Database Schema
The Supabase database consists of the following key tables:

### `profiles`
Represents registered stream creators.
* `id`: UUID (Primary Key)
* `channel_id`: `VARCHAR(24)` (Unique YouTube Channel ID, e.g. starts with `UC`)
* `channel_name`: `TEXT`
* `avatar_url`: `TEXT`
* `total_views`: `BIGINT`
* `subscribers`: `BIGINT`
* `is_special`: `BOOLEAN` (Highlights partner status)

### `streams`
Tracks broadcast data.
* `video_id`: `VARCHAR(11)` (Primary Key, YouTube Video ID)
* `video_title`: `TEXT`
* `storyboard_spec`: `TEXT` (Specification for video thumbnails/frames)

### `games`
Normalizes video games tagged in streams.
* `id`: `VARCHAR(50)` (Primary Key, slug format e.g. `call-of-duty-mobile`)
* `game_title`: `TEXT`
* `game_poster`: `TEXT`

### `clips`
Stores the clipped stream highlights.
* `id`: BIGSERIAL / UUID (Primary Key)
* `video_id`: `VARCHAR(11)` (References `streams.video_id`)
* `timestamp_seconds`: `INT`
* `description`: `VARCHAR(200)` (Clipper tag or notes)
* `username`: `TEXT` (Viewer who created the clip)
* `user_role`: `VARCHAR(20)` (`owner`, `moderator`, `subscriber`, `regular`, `everyone`)
* `profile_id`: UUID (References `profiles.id`)
* `game_id_tag`: `VARCHAR(50)` (References `games.id`)
* `is_hidden`: `BOOLEAN` (Allows creators to moderate clips)
* `is_favorite`: `BOOLEAN` (Protects clip from auto-cleanup)
* `created_at`: `TIMESTAMP`

## 5. UI/UX Guidelines
* **Theme & Vibe**: Rich, premium dark mode aesthetic with glassmorphism/glass effects (`backdrop-filter: blur(16px)`).
* **Color Scheme**: Deep slate/dark background (`rgba(10, 11, 20, 0.8)`), purple accent colors, emerald details for success badges, and amber for warning elements.
* **Unified Visual Style**: Ensure cards, buttons, and popups preserve the dark-mode theme color constraints even if a general light/day mode is toggled, protecting the premium dark gaming theme.
* **Performance Rendering**: Keep background glows composite-promoted using `will-change: transform` and `translate3d` to prevent GPU frame drops on layout transitions.
